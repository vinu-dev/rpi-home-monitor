What to do when .local does not work

If your phone or laptop cannot open a .local address, use the numeric address you already used to reach the device.

  1. Confirm the phone or laptop is on the same WiFi network as the device.
  2. Use the same browser address that opened the device successfully.
  3. Bookmark that address for this WiFi network if your router blocks .local.
If neither page opens

Check that your device is back on the same home WiFi as the camera and server. If the camera is unavailable, reconnect to the setup hotspot and repeat setup. If the server is unavailable, verify it is powered on and reachable from another device on the same network.
